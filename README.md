- Live: https://1hyok.me
- Hosting: GitHub Pages

## Analytics setup

The site is prepared for GoatCounter. No analytics request is sent while `siteCode` in `analytics.js` is empty. After creating a GoatCounter account for this site, put its site code there and publish the change.

The recorded metrics are visits to `1hyok.me` and clicks on the GitHub profile or repository links on this site. Repository click events use the `github-repo:<owner>/<repo>` names. This does not measure people who visit GitHub directly, and a visit is not an exact count of people. GoatCounter defines a visit using an eight-hour in-memory session based on the site ID, IP address, and User-Agent; it says the IP and User-Agent are not stored on disk or in its database.

See [GoatCounter setup](https://www.goatcounter.com/signup), [visitor counting](https://www.goatcounter.com/help/sessions), and [click events](https://www.goatcounter.com/help/events).
